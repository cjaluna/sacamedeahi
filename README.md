# 🇦🇷 Sacame de Ahí

**Guía open source para ejercer tus derechos sobre datos personales en Argentina.**

> Encontrá quién tiene tus datos, qué podés pedir, cómo hacerlo y cómo reclamar si no te responden.

## Objetivo

Sacame de Ahí busca documentar, de forma clara y verificable, los mecanismos disponibles en Argentina para ejercer derechos relacionados con datos personales frente a empresas, plataformas y otras organizaciones.

El proyecto prioriza fuentes oficiales y procedimientos comprobables. No promete que todos los datos puedan eliminarse: pueden existir obligaciones legales de conservación u otras excepciones aplicables.

## ¿Qué queremos documentar?

Para cada entidad:

- qué tipo de datos trata;
- canales oficiales para ejercer derechos;
- acceso a los datos personales;
- rectificación y actualización;
- supresión cuando corresponda;
- oposición o baja de marketing;
- requisitos de identificación;
- plazos informados o legalmente aplicables;
- procedimiento de reclamo;
- fecha de la última verificación;
- fuentes oficiales utilizadas.

## Marco inicial

El proyecto parte del régimen argentino de protección de datos personales, especialmente la Ley 25.326 y los procedimientos y criterios publicados por la Agencia de Acceso a la Información Pública (AAIP).

También documentaremos mecanismos específicos como el Registro Nacional No Llame cuando resulten pertinentes.

## Principios

1. **Argentina primero.** Los procedimientos deben corresponder al marco y servicios disponibles en Argentina.
2. **Fuente oficial primero.** Leyes, AAIP, organismos públicos y documentación oficial de cada entidad tienen prioridad.
3. **Nada de inventar.** Un procedimiento no verificado se identifica expresamente como tal.
4. **Fecha de verificación.** Los canales y procedimientos cambian; cada ficha debe indicar cuándo fue revisada.
5. **Privacidad desde el diseño.** Este repositorio no debe almacenar DNI, teléfonos, correos, solicitudes ni otros datos personales de usuarios.
6. **No es asesoramiento jurídico.** El contenido es informativo y educativo.
