# Metodología de verificación

## Objetivo

Mantener una base verificable y actualizable de procedimientos para ejercer derechos sobre datos personales en Argentina.

## Prioridad de fuentes

1. Normativa argentina vigente y fuentes oficiales del Estado.
2. Agencia de Acceso a la Información Pública (AAIP).
3. Políticas de privacidad y documentación oficial de la entidad analizada.
4. Formularios, portales y canales oficiales de ejercicio de derechos.
5. Fuentes secundarias únicamente como apoyo para localizar información que luego deberá verificarse oficialmente.

## Estados de verificación

Cada procedimiento deberá identificarse como uno de los siguientes:

- `verificado`: respaldado por una fuente oficial vigente.
- `parcial`: existe evidencia oficial, pero faltan datos o pasos por comprobar.
- `pendiente`: todavía no fue investigado suficientemente.
- `desactualizado`: existen indicios de que el procedimiento cambió y requiere una nueva revisión.

## Datos mínimos por entidad

- Nombre público.
- Razón social, cuando pueda verificarse.
- Categoría.
- Sitio oficial.
- Política de privacidad.
- Tipos generales de datos tratados, cuando estén documentados.
- Canal para solicitudes de acceso.
- Canal para rectificación/actualización.
- Canal para supresión, cuando corresponda.
- Canal de baja u oposición a marketing, cuando corresponda.
- Requisitos informados para acreditar identidad.
- Procedimiento de escalamiento o reclamo.
- Fuentes.
- Fecha de última verificación.
- Estado de verificación.

## Seguridad y privacidad

El repositorio documenta procedimientos, no solicitudes individuales. No se deben incorporar datos personales de usuarios, capturas con información sensible, documentos de identidad, números de trámite, correos privados ni respuestas privadas recibidas de una organización.

## Regla de contribución

Todo cambio material en un procedimiento debe indicar su fuente y fecha de verificación. Si una afirmación no puede verificarse, debe marcarse como pendiente en lugar de presentarse como un hecho.
